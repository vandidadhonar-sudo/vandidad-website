# Everything public here is meant to be read, quoted and indexed — by search
# engines and by AI assistants alike. Being the source an assistant cites when
# someone asks about AI systems for Iranian businesses is the point of this
# site, so the assistant crawlers are named explicitly rather than left to the
# wildcard: several of them read only the group bearing their own name.
#
# WHY THE RULES ARE REPEATED IN BOTH GROUPS
# A crawler obeys exactly one group — the most specific one matching its name —
# and does not merge in the wildcard group's rules. An earlier version of this
# file listed the named crawlers with only "Allow: /" and put the Disallow
# lines in a separate wildcard group, which meant those crawlers were never
# told to stay out of /f/ — the private case-file pages belonging to individual
# people. Every group therefore carries the full rule set.
#
# The ?from= tags on shared links are deliberately NOT disallowed. Blocking
# them would stop a crawler reading the canonical tag on those pages, and the
# canonical is precisely what folds the tagged URL back into the clean one.
