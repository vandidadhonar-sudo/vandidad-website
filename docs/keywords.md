# عبارت‌های هدف — فهرست خودکار

**این فایل با دست نوشته نمی‌شود.** هر بار که محتوا ساخته می‌شود از روی
خودِ مقاله‌ها بازتولید می‌گردد، پس هیچ‌وقت از محتوا عقب نمی‌افتد.

ساختنش:

```
python3 tools/seo_report.py
```

## چه چیزی اندازه گرفته شده

| ستون | یعنی چه |
|---|---|
| **تکرار** | چند بار عبارت هدف در متن آمده. کمتر از دو بار یعنی صفحه آشکارا دربارهٔ آن عبارت نیست. |
| **چگالی** | سهم عبارت از کل کلمه‌ها. گوگل سال‌هاست می‌گوید عدد هدفی وجود ندارد؛ اینجا فقط **سقف** است (2.5٪). زیر آن، به این عدد نگاه نکن. |
| **عنوان / توضیح** | آیا عبارت در چیزی که جستجوکننده پیش از کلیک می‌بیند هست. |
| **آغاز** | آیا در 150 کلمهٔ اول آمده — جایی که خواننده تصمیم می‌گیرد بماند. |
| **لینک بیرون / درون** | لینک‌های داخلی، در هر دو جهت. ستون «درون» مهم‌تر است: صفحه‌ای که هیچ صفحهٔ دیگری به آن لینک نداده، فقط از نقشهٔ سایت پیدا می‌شود و دیرتر از همه خزیده می‌شود. |
